# Actividad adicional de SQL

Las consultas siguen el codelab [Cómo usar SQL para leer y escribir en una base de datos](https://developer.android.com/codelabs/basic-android-kotlin-compose-sql?hl=es-419). `Email.db` es la base de ejemplo del proyecto oficial [SQL Basics](https://github.com/google-developer-training/android-basics-kotlin-sql-basics-app/tree/compose), distribuido con la licencia incluida.

Ejecuta `python consultas.py` para obtener `resultados.json`. El script copia la base en memoria antes de insertar, actualizar y eliminar para conservar intacto el archivo original. Los resultados se obtienen mediante SQLite de Python; la ejecución en el Database Inspector de Android Studio requiere una verificación independiente.
