# Laboratorio 7

Aplicación Android con Jetpack Compose y Room para registrar usuarios y administrar asistencia.

El proyecto utiliza Room 2.8.5 y KSP.

Para compilar:

```powershell
./gradlew.bat :app:assembleDebug
```

La carpeta `codelab-sql` contiene las consultas realizadas con la base de ejemplo del codelab.
